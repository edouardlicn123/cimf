# Stage 5 — 模块脚手架升级与规范固化计划

> 版本：v1.0 | 创建日期：2026-07-09 | 计划状态：待执行

---

## 一、背景与目标

### 问题

当前 `ModuleScaffoldService.create_module()` 生成的模块模板过于简陋：

- `models.py` 继承 `models.Model` 而非 `BaseModel`
- `views.py` 手写 `JsonResponse` 而非 `json_success`/`json_error`
- **没有** `apps.py`（Django AppConfig）
- **没有** `services.py`（无 Service 继承 BaseService）
- **没有** `urls.py`（无标准化路由）
- **没有** `templates/` 目录

新开发者在此模板上开发，每个模块都从头造轮子，导致核心工具（BaseModel、BaseService、json_success 等）在模块层未被充分使用。

### 目标

```
傻瓜式脚手架 + 制度规范 = 模块标准化
```

| 维度 | 方案 | 效果 |
|------|------|------|
| 工具 | 升级 `create_module` 生成完整骨架 | 从源头杜绝"造轮子" |
| 基类 | 定义 `ModuleServiceBase` | 模块 Service 无需重复 Node CRUD |
| 制度 | 更新 A02 文档 + 添加开发 Checklist | 新开发者有据可依 |

### 批次 A：定义 `ModuleServiceBase`（🔴高，~20min）

在 `core/services/module_base.py` 新增模块服务基类，封装 Node 型模块的通用 CRUD 模式。

```
core/services/module_base.py
└── ModuleServiceBase(BaseService)
    ├── model_class         ← 子类定义（如 CustomerFields）
    ├── node_type_slug      ← 子类定义（如 "customer"）
    ├── field_mapping       ← 子类定义（数据 → 字段映射）
    │
    ├── get_by_node_id(node_id)           ← 通过 Node ID 查
    ├── create_with_node(user, data)      ← 创建 Node + Fields（事务）
    ├── update_with_node(id, user, data)  ← 更新 Fields
    ├── delete_with_node(id)              ← 删除 Fields + Node（事务）
    ├── import_row(data, user)            ← 导入行（直接建 Node + Fields）
    └── init_sample_data()                ← 样本数据批量创建
```

**关键设计：** `ModuleServiceBase.create_with_node` 定义：

```python
class ModuleServiceBase(BaseService):
    model_class = None
    node_type_slug = None
    field_mapping = {}

    @classmethod
    def create_with_node(cls, user, data):
        with transaction.atomic():
            node = NodeService.create_node(cls.node_type_slug, {}, user)
            fields = cls._build_fields(data, {"node": node})
            return cls.model_class.objects.create(**fields)
    
    @classmethod
    def _build_fields(cls, data, extra):
        result = dict(extra)
        for field_name, _type in cls.field_mapping.items():
            val = data.get(field_name)
            if val is not None and val != "":
                try:
                    result[field_name] = _type(val) if _type is not str else val
                except (ValueError, TypeError):
                    result[field_name] = val
        return result

    @classmethod
    def delete_with_node(cls, entity_id):
        with transaction.atomic():
            instance = cls.model_class.objects.filter(id=entity_id).first()
            if not instance:
                return False
            node = instance.node if hasattr(instance, 'node') else None
            instance.delete()
            if node:
                node.delete()
            return True
```

# 开发规范

> CIMF 项目开发规范。各领域详细规则已独立为 quick 版规范（见 `docs/阅读指南.md`）。

---

## 快速参考

| 命令 | 说明 |
|------|------|
| `./run.sh` | 启动/管理服务 |
| `./venv/bin/python manage.py check` | 检查项目（无 CIMF_W001 警告） |
| `./venv/bin/python manage.py test` | 运行测试 |
| `./venv/bin/python update_progress.py "描述"` | 更新进度 + 版本号 |
| `./manage.py generate_snapshot` | 自动更新代码快照 |

---

## 开发流程

1. 新会话 → 读 `AGENTS.md` → 按需读 `docs/阅读指南.md`
2. 修改代码 → 读对应 quick 版规范（A02/A04/A05/A08/B05/B06）
3. 改模板 → 先读 `docs/templates.md` 了解继承关系
4. 改模块（customer 等）→ 先读 `docs/模块快照/{module}.md`
5. 修改后 → 跑 `manage.py check` + 增量 ruff 检查
6. 更新进度 → `update_progress.py "描述"`

## 存储目录

| 目录 | 用途 |
|------|------|
| `storage/logs/` | 日志文件（cimf.log, error.log, security.log） |
| `storage/uploads/` | 用户上传文件 |
| `storage/backups/` | 数据库备份 |

> `settings.py` 启动时自动创建以上目录。

## 关键规则速查（各层详见对应 quick 版规范）

| 层 | 一句话规则 | 详见 |
|----|-----------|------|
| 服务层 | `.first()` 后必须检查 None；`datetime.now()` → `timezone.now()` | `A05_quick` |
| 视图层 | JSON API 必须 `@login_required_json`；POST 必须有 `{{ csrf_token }}` | `A05_quick` |
| 模板层 | 只用 Jinja2 语法；外键访问前检查 None；过滤器用括号 `\|date('Y-m-d')` | `A04_quick` |
| 模型层 | ForeignKey 用 `SET_NULL`；JSONField default 用 `list` 而非 `[]` | `A05_quick` |
| 模块 | module.py 的 MODULE_INFO 字典必须完整；node 类型需 taxonomies | `A02_quick` |
| 表单 | 继承 `BootstrapFormMixin`；choices 统一在 `constants.py` 定义 | `B04` |

## 3. Jinja2 语法规范

### 3.1 过滤器必须用括号
- ✅ `{{ x\|default("y") }}` ❌ `{{ x\|default:"y" }}`
- ✅ `{{ d\|date("Y-m-d") }}` ❌ `{{ d\|date:"Y-m-d" }}`

### 3.2 CSRF Token
- ✅ `{% include "includes/csrf.html" %}` — 标准 POST 表单用法，渲染为 `<input type="hidden" name="csrfmiddlewaretoken" value="...">`
- ✅ `{{ csrf_token_value }}` — 原始 token 值字符串，用于 AJAX 请求或在 `<meta>` 标签中使用
- ❌ `{% csrf_token %}`（Django 语法，Jinja2 无效）
- ❌ `{{ csrf_input }}`（不存在于本项目的 Jinja2 环境中）

### 3.3 字典遍历 / 三元 / 链式调用
- `{% for k, v in dict.items() %}` — 必须加 `()`
- `{{ value if condition else default }}`
- `{{ (x\|default("y")).split(",") }}` — 链式调用加括号分组

### 3.4 常用过滤器

| 过滤器 | 用途 | 示例 |
|--------|------|------|
| `default` | 默认值 | `{{ v\|default("-") }}` |
| `default_if_none` | 仅 None 时 | `{{ v\|default_if_none("无") }}` |
| `date` | 日期格式化 | `{{ v\|date("Y-m-d H:i") }}` |
| `truncatechars` | 字符截断 | `{{ t\|truncatechars(50) }}` |
| `slice` | 字符串切片 | `{{ t\|slice(0, 50) }}` |
| `tojson` | JSON 安全输出 | `{{ d\|tojson }}` |
| `safe` | 标记安全 HTML | `{{ h\|safe }}`（慎用） |
| `length` / `filesizeformat` | 长度/文件大小 | `{{ l\|length }}` |

## 5. 变量命名规范

**通用**：下划线命名 / 有意义名称 / 避免缩写 / 布尔加 `is_`、`has_` 前缀

**按功能**：过滤参数 `filter_` / 搜索 `search` / 分页 `page_obj` / 统计 `stats_` / 列表用复数 / 单对象用单数

**保留变量名（请勿覆盖）**：`user` `system_name` `settings` `system_settings` `messages` `csrf_token_value` `request` `timestamp` `node_types` `node_type` `node`

## 8. 易错点清单

| 类目 | 检查项 | 正确写法 |
|------|--------|----------|
| Jinja2 语法 | `default(date` 过滤器 | 必须用 `()` 而非 `:` |
| Jinja2 语法 | `csrf_token_value` | `{{ csrf_token_value }}`（变量非 tag） |
| Jinja2 语法 | `dict.items()` | 必须加括号 |
| 空值处理 | 用户输入 | `{{ value\|default("-") }}` |
| 空值处理 | 外键访问 | 先 `{% if obj.relation %}` 再取值 |
| 空值处理 | 对象属性比较 | 先 `{% if obj and obj.attr == val %}` |
| HTML 结构 | Modal 位置 | 必须在 `<table>` 外部 |
| 表单安全 | POST 表单 | 必须含 `{% include "includes/csrf.html" %}` 或 `{{ csrf_token_value }}` |
| 表单安全 | JS 嵌入 | 用 `{{ value\|tojson }}` |

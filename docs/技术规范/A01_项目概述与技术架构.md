## 一、项目简介

### 1.1 项目概述

CIMF = Corporate Internal Management Framework，企业内部管理框架。

灵感来自 Drupal，通过 node、field、taxonomy 等功能实现 CRM 等系统的管理功能。

### 1.2 功能特点

| 特性 | 说明 |
|------|------|
| 🔐 **角色权限体系** | 经理/组长/员工三级权限管理，可精细控制节点操作权限 |
| 📊 **模块化节点系统** | 插件式模块架构，支持动态加载/卸载 |
| 📝 **26种自定义字段类型** | 文本、数字、布尔、文件、图片、邮箱、电话、日期、地理位置、颜色、身份识别、隐私脱敏等 |
| 🗂️ **词汇表管理** | 预置分类（国家、客户类型、行业、企业性质、客户等级等） |
| 🗺️ **中国行政区划** | 省市县三级联动字段，支持级联选择 |
| 💧 **水印保护** | 网页动态水印 + 导出文件水印 |
| 📥 **数据导入导出** | 支持 CSV/Excel 格式，可自定义字段和过滤条件 |
| ⏰ **定时任务系统** | 可扩展的 Cron 任务（时间同步、缓存清理） |
| 🧪 **核心模块测试** | 核心模块单元测试和集成测试 |
| 🏠 **首页快捷入口** | 3×2 卡片布局，支持拖拽自定义 |

### 1.3 技术栈

| 类别 | 技术 |
|------|------|
| 后端 | Python 3.12 / Django 6.0 |
| 数据库 | SQLite |
| 模板 | Jinja2 |
| 测试 | Django TestCase |

## 二、字段类型系统

### 2.1 字段类型总览

项目提供 26 种自定义字段类型，可灵活配置：

| 类别 | 字段类型 |
|------|----------|
| 文本 | `string`, `string_long`, `text`, `text_long`, `text_with_summary` |
| 数值 | `boolean`, `integer`, `decimal`, `float` |
| 媒体 | `file`, `image` |
| 联系 | `link`, `email`, `telephone` |
| 时间 | `datetime`, `timestamp` |
| 特殊 | `geolocation`, `color`, `ai_tags`, `identity`, `masked`, `biometric`, `address`, `gis`, `entity_reference` (实体引用) |
| 中国 | `region_select` (省市区联动) |

| 字段类型 | 说明 | 详细规范 |

| `datetime` | 日期时间 | - |

### 3.2 核心模块说明

| 模块 | 说明 |
|------|------|
| `core/` | 核心应用，包含用户、权限、系统设置等基础功能 |
| `core/node/` | 节点核心系统，NodeType/Node CRUD、模块分发（module_dispatch） |
| `core/fields/` | 26种自定义字段类型的实现 |
| `core/services/` | 核心服务层，提供业务逻辑封装 |
| `core/smtp/` | 邮件服务模块 |
| `core/importexport/` | 数据导入导出功能 |
| `core/marketplace/` | 模块市场，在线下载安装模块 |
| `modules/` | 业务模块目录，插件式架构 |

### 3.3 业务模块说明

| 模块 | 类型 | 说明 |
|------|------|------|
| customer | node | 海外客户信息管理，支持 20+ 字段，含 LinkedIn |
| clock | system | 时钟/日历展示，仪表盘快捷卡片 |
| smtptest | tool | SMTP 邮件测试工具 |
| whatsapp | tool | WhatsApp 批量发送信息模块 |

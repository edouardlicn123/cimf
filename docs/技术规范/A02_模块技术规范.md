# 模块技术规范

> v3.9 | 2026-05-06

定义 cimf-v2 业务模块系统技术规范。完整示例见 _A02_补充材料.md_。

---

## 一、概述

**核心概念**：Module（独立业务单元，对应 Django 子应用）→ NodeType（业务分类入口）→ Node（公共字段）→ {Module}Fields（业务数据模型）

**模块类型**：
| 类型 | 说明 | 创建类型 | 显示位置 |
|------|------|----------|----------|
| `node` | 事务节点模块 | NodeType | 事务处理页面 |
| `system` | 系统模块 | 无 | 仪表盘/功能卡片 |
| `tool` | 协作工具模块 | ToolType | 协作工具页面 |

常量：`from core.constants import ModuleType` → `ModuleType.NODE/SYSTEM/TOOL`

---

## 二、架构

**目录**：`modules/{id}/` 含 `module.py`(必选)、`apps.py`、`models.py`、`services.py`、`views.py`、`urls.py`、`templates/{id}/`。核心系统：`core/node/`(NodeType,Node) + `core/module/`(Module,ToolType)。

**模型关系**：`Module(type=node) → NodeType → Node → {Module}Fields`；`Module(type=system)` 无类型；`Module(type=tool) → ToolType`

---

## 三、module.py 规范

### 3.1 必选字段
```python
MODULE_INFO = {'id': 'customer', 'name': '客户信息（海外）', 'type': 'node', 'version': '1.0.0'}
```

### 3.2 可选字段
| 字段 | 类型 | 说明 |
|------|------|------|
| `author` / `description` | string | 作者/描述 |
| `icon` | string | Bootstrap Icons 类名 |
| `require` | list[string] | 依赖模块列表 |
| `dashboard_cards` | list | 仪表盘卡片配置 |
| `taxonomies` | list | 词汇表定义，安装时自动创建 |
| `permissions` | list | 自定义权限 |
| `export_fields` | list | 导出字段配置 |
| `dashboard_stats` | bool | 支持仪表盘统计 |
| `frontpage_card_clickable` | bool | 卡片可点击（默认True） |
| `views` | dict | 视图函数映射 |
| `models` | list[string] | 关联模型列表 |

注意：模块市场下载后不会自动安装，需手动完成安装和启用。

### 3.3 taxonomies
```python
'taxonomies': [{'slug': 'supplier_type', 'name': '供应商类型', 'items': ['原材料', '设备', '服务']}]
```
字段：`slug`(必填,全局唯一) / `name`(必填) / `items`(必填,list)。安装行为：不存在则创建，已存在则跳过仅补充缺失项。

### 3.4 permissions
```python
'permissions': [{'key': 'view_others', 'name': '查看别人的内容'}]
```
字段：`key`(必填, 最终权限`node.{module_id}.{key}`) / `name`(必填)。基础权限(node.{id}.create/read/update/delete)自动添加，自定义权限从配置读取。

### 3.5 dashboard_cards
```python
'dashboard_cards': [{'id': 'supplier_card', 'name': '供应商', 'template': 'supplier/dashboard_card.html'}]
```
字段：`id`(必填) / `name`(必填) / `template`(必填) / `color_start` / `color_end`(HEX渐变色)。统计方法：`get_count() -> int`、`get_recent_count(days=7) -> int`

### 3.6 export_fields
```python
'export_fields': [{'name': 'supplier_name', 'label': '供应商名称', 'type': 'string', 'required': True}]
```
字段：`name`(必填) / `label`(必填) / `type`(必填) / `required`。
类型：`string/string_long/text/email/telephone/link/decimal/integer/float/date/datetime/boolean/fk/region/taxonomy/image/file`

### 3.7 require
```python
'require': ['customer']          # 单个/多个依赖，[]为无依赖
```

### 3.8 install_on_init
```python
'install_on_init': True    # 默认，初始化自动安装
'install_on_init': False   # 初始化跳过，手动仍可装
```

### 3.9 SQL 钩子
```python
def get_install_sql() -> str|None:    # 安装迁移后执行
def get_uninstall_sql() -> str|None:  # 卸载删除前执行
```

### 3.10 models
```python
'models': ['CustomerFields']  # 安装时验证表是否存在
```
require验证：安装/启用时递归检查依赖已安装且启用，检测循环依赖。require不存在或为[]视为无依赖，依赖不存在于系统中跳过。

## 四、核心模型

### 4.1 Module
`module_id`(unique) / `name` / `version` / `author`(blank) / `description`(blank) / `icon`(default bi-wrench) / `path` / `is_installed` / `is_active` / `is_system` / `module_type`(default node) / `install_on_init`(default True) / `installed_at`(null) / `activated_at`(null)

### 4.2 NodeType
`name` / `slug`(unique,db_index) / `description`(blank) / `icon`(default bi-folder) / `author`(blank) / `fields_config`(JSONField,default=list) / `is_active`(default True)

### 4.3 ToolType
`name` / `slug`(unique,db_index) / `description`(blank) / `icon`(default bi-wrench) / `author`(blank) / `is_active`(default True)

### 4.4 Node
```python
class Node(BaseModel):
    node_type = ForeignKey(NodeType, CASCADE, related_name='nodes')
    created_by = ForeignKey(AUTH_USER_MODEL, SET_NULL, null=True, related_name='created_nodes')
    updated_by = ForeignKey(AUTH_USER_MODEL, SET_NULL, null=True, related_name='updated_nodes')
```

### 4.5 字段模型
```python
class CustomerFields(models.Model):
    node = OneToOneField(Node, CASCADE, related_name='customer_fields')
    customer_name = CharField(max_length=200, unique=True)  # + 其他业务字段
```

## 五、模块管理

**生命周期**：`未注册 → 注册 → 安装 → 启用 ↔ 禁用`
安装流程：检查目录/migrations → 验证表 → makemigrations → migrate → 验证表 → 标记is_installed → 同步类型 → 创建词汇表

**状态**：未注册(目录存在)/已注册(数据库)/已安装(迁移完成)/已启用(可使用)/已禁用

**类型过滤**：`node`创建NodeType/显示事务页；`system`不创建类型/仅仪表盘；`tool`创建ToolType/显示协作工具页

**管理功能**：扫描(AST解析module.py)/安装(验证依赖→迁移→创建类型→词汇表)/启用/禁用(验证依赖→启用/禁用类型)

**错误处理**：迁移失败抛RuntimeError；表不存在但标记已安装则取消标记重新迁移；迁移后表未创建抛异常

## 六、开发规范

**服务层**：`class CustomerService:` 含 `get_list(search,**filters)` / `create(user,data)`

**视图**：`@login_required def node_list(request)` / `def node_create(request)`

**URL**：`app_name='customer'; path('',views.node_list,name='list')` + create/view/edit/delete

**动态加载**：`modules/urls.py` 用 `try_include_module()` 从数据库动态加载，文件夹不存在时仍能启动

**模板**：`{% extends "frames/frame_node.html" %}` + `url('node:module_page','customer')` 反向解析

---

## 七、权限控制

**类型**：`module.view/install/enable/disable`(管理) / `node.{slug}.view/create/edit/delete`(自动添加) / `node.{slug}.view_others/edit_others/delete_others`(自定义)

**检查**：is_admin → 创建者 → has_permission。通过 `module.py` 的 `permissions` 定义，`PermissionService.has_permission()` 检查。

---

## 八、数据库迁移

**命令**：`manage.py makemigrations {id}` / `manage.py migrate`
**命名**：`0001_initial.py` / `0002_{feature}.py`
**验证**：检查 `django_migrations` 记录 + 所有模型表存在。`is_installed=True` 但表不存在时取消标记重新迁移。

## 十、功能卡片系统

**概述**：首页3×2网格(6槽)，支持拖拽，位置存于`SystemSetting(key=user_dashboard_card_positions)`。

**模板规范**：根元素`<div class="module-card h-100" draggable="true" data-module="{id}">`，内联渐变色背景，内容居中。变量：`module_id`/`total`/`recent`(自动注入)。

**API**：`GET /api/user/dashboard/cards/` 返回 `positions`/`available_modules`/`module_stats`/`module_contents`(预渲染HTML)。`POST /api/user/dashboard/cards/save/` 保存布局。

**支持**：所有类型均可在首页仪表盘显示；tool类型额外在协作工具首页显示。

---

## 十一、协作工具页面

**概述**：tool类型专用，`/tools/` → `tools_index` → `tools_dashboard.html` → `frame_tools.html`

**视图规范**：工具模块视图必须手动传 `tools` 变量，否则侧边栏链接消失：
```python
tools = ToolType.objects.filter(slug__in=Module.objects.filter(module_type='tool',is_active=True).values_list('module_id',flat=True), is_active=True)
```
**模板**：`{% extends "frames/frame_tools.html" %}` / `{% set active_section = 'calc' %}`(slug用于高亮)

**无models.py**：跳过迁移直接标记安装。

**类型过滤(完整)**：node→事务卡片+侧边栏；system→仅事务卡片；tool→协作卡片+侧边栏。

## 十二、模块市场配置

**marketplace.json**：`core/marketplace/marketplace.json`。字段：`id`/`name`/`description`/`download_url`/`version`。

**ZIP要求**：直接包含文件，无外层文件夹。必需：`module.py`/`apps.py`/`views.py`/`urls.py`。可选：`models.py`/`migrations/`/`templates/`/`services.py`。

**流程**：获取列表 → 下载ZIP → 解压到modules/ → 迁移 → 注册启用 → 清理。

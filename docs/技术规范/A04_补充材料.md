## 4. 性能优化（完整）

### 4.1 查询优化

```python
# ❌ N+1 查询
customers = Customer.objects.all()
# 模板中访问 customer.customer_type.name 会为每条数据触发额外查询

# ✅ 使用 select_related
customers = Customer.objects.select_related(
    'customer_type', 'country', 'enterprise_type', 'customer_level'
).all()

# ❌ 每次访问都触发 count() 查询
{{ taxonomy.items.count }}

# ✅ 在视图层预计算
taxonomies = Taxonomy.objects.prefetch_related('items')
for t in taxonomies:
    t.item_count = t.items.count()
```

### 4.2 渲染优化

| 优化项 | 说明 |
|--------|------|
| 在视图层过滤数据 | 避免模板中复杂的 `{% if %}` 过滤 |
| 使用 `only()` | 只选择需要的字段，减少内存占用 |
| 分页 | 大数据集必须分页，默认每页 20-50 条 |
| 避免模板中调用方法 | 模板中调用方法会触发额外查询 |

### 4.3 缓存策略

- 静态资源使用版本号：`{{ static('js/app.js') }}?v={{ timestamp }}`
- 不缓存用户相关数据
- 使用 Django 缓存框架缓存复杂计算结果

## 5. Accessibility（完整）

### 5.1 表单规范

```html
<!-- ❌ 错误：缺少 label -->
<input type="text" name="name">

<!-- ✅ 正确：使用 label -->
<div class="mb-3">
    <label class="form-label" for="name">姓名 *</label>
    <input type="text" name="name" id="name" class="form-control" required>
</div>

<!-- ❌ 错误：placeholder 不能替代 label -->
<input type="text" placeholder="请输入姓名">

<!-- ✅ 正确：两者都提供 -->
<label class="form-label" for="name">姓名</label>
<input type="text" id="name" placeholder="请输入姓名">
```

### 5.2 语义化标签

| 场景 | 推荐标签 |
|------|----------|
| 页面标题 | `<h1>`（每个页面只有一个） |
| 区块标题 | `<h2>` - `<h6>` |
| 导航 | `<nav>` + `aria-label` |
| 表格标题 | `<caption>` 或 `aria-label` |
| 按钮 | `<button>` 而非 `<a>` |
| 时间 | `<time>` + `datetime` 属性 |

### 5.3 键盘导航

```html
<div class="modal" tabindex="-1" role="dialog" aria-labelledby="modalTitle">
    <div class="modal-dialog" role="document">
        <div class="modal-content">
            <div class="modal-header">
                <h5 class="modal-title" id="modalTitle">标题</h5>
                <button type="button" class="btn-close" data-bs-dismiss="modal" aria-label="关闭"></button>
            </div>
            ...
        </div>
    </div>
</div>

<button type="button" class="btn btn-sm btn-outline-danger"
        onclick="if(confirm('确定删除?')) this.form.submit()">删除</button>
```

- 重要信息不依赖颜色传达（同时使用图标或文字）
- 错误提示使用红色 + 图标

## 8. CSRF Token 实现细节

```python
# cimf_django/context_processors.py
def csrf_token(request):
    from django.middleware.csrf import get_token
    token = get_token(request)
    return {'csrf_token_value': token}
```

**includes/csrf.html 内容**：
```html
<input type="hidden" name="csrfmiddlewaretoken" value="{{ csrf_token_value }}">
```

**使用方式**（推荐）：
```html
<form method="post">
    {% include "includes/csrf.html" %}
</form>
```

**常见问题**：

| 问题现象 | 可能原因 | 解决方案 |
|----------|----------|----------|
| CSRF 验证失败 | 未在表单中包含 CSRF token | 使用 `{% include "includes/csrf.html" %}` |

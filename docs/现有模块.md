## 模块文档架构规范

每个模块必须在其根目录包含 `SNAPSHOT.md`，格式如下：

```
# <module_id> 模块快照

## 模型
| 模型 | 字段 |
|------|------|
| <ModelName> | <fields...> |

## 服务类
| 方法 | 参数 |
|------|------|
| <ServiceClass.method> | <params...> |

## 文件
- `modules/<module_id>/models.py` (N 行)
- `modules/<module_id>/services.py` (N 行)
- `modules/<module_id>/views.py` (N 行)
- `modules/<module_id>/forms.py` (N 行)
- `modules/<module_id>/module.py` (N 行)
```

### 维护方式

| 阶段 | 操作 | 说明 |
|------|------|------|
| **创建** | `ModuleScaffoldService.create_module()` 自动生成骨架 | 新模块创建时自动产出空 SNAPSHOT.md |
| **同步** | `python manage.py generate_snapshot` 自动填充 | 扫描 AST 后填入真实模型/服务/文件行数 |
| **提交** | 修改模型/服务后重新生成 `generate_snapshot --module <name>` | 保持与代码同步 |

> **注意：** `SNAPSHOT.md` 为固定文档格式，禁止自行修改格式结构。字段截断（`...`）由 `generate_snapshot` 自动处理。
